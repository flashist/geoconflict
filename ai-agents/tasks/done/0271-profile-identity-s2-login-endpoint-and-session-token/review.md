## Accepted residuals (shared, do-not-re-litigate)
- Strict `Bearer ` spelling (R3) — What: `resolveCaller` accepts only the exact, case-sensitive `Bearer ` prefix with a single space; `bearer`, or extra spaces or tabs, answers 401 `session_invalid`. · Why (structural): the only Bearer client is S4's own `ProfileSession`, which sends the exact spelling. A strict parse keeps one unambiguous format and gives a stale or garbage header a loud 401 (plan §4). Rejected alternative: a case-insensitive, whitespace-tolerant parse, which adds parsing surface for no current caller. Owner accepted 2026-09-15. · Re-raise only if: a client other than S4's (a third party, another platform SDK, a proxy that rewrites the header) ever sends Bearer tokens to the profile API.
