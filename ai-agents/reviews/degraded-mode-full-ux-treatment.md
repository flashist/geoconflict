## Accepted residuals (do-not-re-litigate)

- **Degraded sessions bypass the `citizenship_ui` experiment gate.** `CitizenshipCard.connectedCallback()` treats `isYandexDegraded()` as enabled without consulting the flag. Original rationale (round 1): in SDK-init-failure degraded mode `getFlags()` cannot run, so the flag is unknowable — the alternative was a silently missing surface in production. **Extended in round 3:** the broadened `isYandexDegraded()` (player-object check) also classifies "SDK healthy but boot `getPlayer()` failed/timed out" as degraded; in that subclass the flag *is* technically fetchable but is still bypassed — same player-facing cost, kept for gate simplicity. *Cost accepted:* users outside the experiment rollout can see the degraded card during (rare) degraded sessions, and `Citizenship:Seen` can fire for them. *Re-raise only if:* `citizenship_ui` becomes a measured A/B where degraded-session exposure contaminates results, or `Session:PlatformInitTimeout` volume turns out non-trivial (which would also justify the cached-flag variant considered and rejected as over-engineering on 2026-07-02).
- **No active SDK/player retry, no late-recovery notification path.** Per the task's Locked Decisions; a recovered player reloads or starts their next match. `isYandexDegraded()` classifies state at render time only.
- **`openYandexAuthDialog()`'s `getPlayer()` re-fetch stays un-bounded** (`FlashistFacade.ts:901`). Post-C2-fix the CTA only renders when a player object was already obtained this session, so the re-fetch pathway is proven-working; the coder-handoff spec itself marked a timeout there optional and advised against adding it speculatively without a test. *Re-raise only if:* field reports/analytics show auth-dialog taps hanging for real players.
- **Incidence caveat (informational):** a boot `getPlayer()` that *rejects quickly* does not fire `Session:PlatformInitTimeout` (only deadline expiry does), so that event under-counts the C2 subclass. Accepted per "no new analytics event" locked decision.
